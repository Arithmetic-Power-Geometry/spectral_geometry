# P43 novelty-first audit and structural reduction

## Exact identity
For any binary graph code C, the ten-variable genus-two refined enumerator W2(C) specializes under separating factorization Phi to W1(C)(x)W1(C)(z), since each ordered codeword pair (u,v) contributes independently to the two genus-one factors. By linearity, a signed combination sum_C a_C W2(C) belongs to ker Phi iff sum_C a_C W1(C)(x)W1(C)(z)=0. This is an exact elementary identity, not a newly established physical theorem.

P42 reports rational ranks of the spans at n=5: rank(W2)=14, rank(Phi W2)=13, and at n=6: 27 and 23, respectively, and a signed integer n=5 relation. Such relations are virtual linear combinations, not positive physical CFT pairs. The P42 file contains an explicit certificate, but the P43 task did not independently rerun it.
