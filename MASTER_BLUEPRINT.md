# Master Blueprint v1.0 — 2026-10-30

## Scientific objective
Develop rigorous, genuinely novel theorems on which spectral measurements identify positive quadratic forms, integral lattice structures and Narain compactification geometries; classify robust obstructions and determine minimal information requirements. Assess quantum coding or cryptography applications **only after** independent bridges are proved.

## Existing results (not to be republished as new)
1. Fixed-basis two-torus background reconstructible from five particular charge-labelled zero-mode energies (sufficiency, not optimality).
2. Restricted rectangular unlabelled reconstruction with stated parameter assumptions; B-to-minus-B energy reflection; orientation-sensitive spin distinctions. Worldsheet parity is established prior art.
3. Fixed rational two-torus first spin-resolved discrepancy T(b)=(133-6b+18b^2)/53 on 0<b<1/2, and endpoint symmetry; source results concern exact zero modes.
4. Exact six-vertex graph enumeration, refined higher-genus code polynomials and integral non-splitting sufficient certificates. Coarse signature not LC invariant; implemented Gaussian sign not yet a physically normalized genus-two partition-function difference; Kneser-type splitting methods are established.

## Paper workstreams and independence
- **PAPER-01 (priority):** Minimal Spectral Data for Reconstruction of Narain Geometry. Main questions: lower bounds on nonadaptive/adaptive charge-labelled probes; identifiability of entire background vs moduli orbit; stable reconstruction under specified noise; counterexamples to overstrong minimality. Must explicitly compare to existing five-probe baseline.
- **PAPER-02:** Higher-Dimensional Inverse Spectral Rigidity and Non-Identifiability. Nonproduct d>=3 results and full O(d,d;Z) orbit interpretation required. No generic theorem assumed.
- **PAPER-03:** Certified Higher-Genus Distinguishability in Code-Based Narain CFTs. Require correct physical normalization, modular covariance, degeneration, code equivalence/duality checks, and new examples beyond published genus-two comparisons.
- **PAPER-04 (conditional application):** Spectral/Code Invariants and Quantum Stabilizer Performance. Require explicit code construction, correct equivalence, distance and logical noise-performance comparisons; no application claim based solely on lattice similarity.
- **PAPER-05 (exploratory only):** Integral Lattice Splitting and Complexity. Requires advance beyond classical Kneser-type decomposition criteria and genuine complexity or exact-theorem novelty.
- **Cryptography:** RSA factoring and lattice-based encryption are separate topics; no attack, complexity advantage or security consequence is inferred from current Narain spectra.

## Strict writing gate
No manuscript drafted merely because a numerical pattern is striking. GO requires (a) precise independently reviewed mathematical statement, (b) complete proof or sound certified computation, (c) verified novelty against strongest prior art, (d) checked counterexamples and scope, (e) reproducible data, (f) traceable authentic citations. A failed result remains permanently documented.

## Evidence/references policy
Use dated evidence records with source URLs, access date, precise claims, methods, logs and negative findings. `reference/reference.bib` contains only individually verified bibliographic metadata, no placeholders. `reference/verification_register.csv` links each BibTeX key to checked publisher/DOI URL, verification date and limits. References present in source papers are not automatically verified for the new programme. At each prompt, commit changes to this repo and verify SHA and paths. Source PDFs must be preserved intact when uploaded; never reconstruct PDF from extracted text.
