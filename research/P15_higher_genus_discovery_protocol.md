# P15 — Higher-genus Narain discovery protocol (new research track, not manuscript)

Date: 2026-10-30. P14 remains NO-GO for PAPER-01 and PAPER-02.

## Candidate question
Can one construct a physically normalized genus-two Narain observable that distinguishes two genus-one-isospectral theories, with a new minimality, exact threshold, or complexity guarantee not already present in Henriksson–Kakkar–McPeak (JHEP 04 (2023) 011) or other higher-genus code-CFT literature?

## Baseline and immediate novelty threat
Higher-genus separation of genus-one-isospectral code CFTs is already known. Mere reproduction, a differently plotted Gaussian lattice sum, or a new numerical example without an independent theorem is NO-GO.

## Formal object (not yet a physical partition function)
For a rank-d momentum-winding lattice with left/right vectors p_L,p_R and a genus-two period matrix Omega=X+iY, Y positive definite, the Siegel–Narain lattice theta kernel schematically sums over two independent lattice vectors:
sum_{gamma_1,gamma_2} exp(pi i sum_{a,b} X_ab (p_La·p_Lb-p_Ra·p_Rb) - pi sum_{a,b}Y_ab (p_La·p_Lb+p_Ra·p_Rb)).
Conventions for alpha', factors of two, cocycles and measure must be fixed from primary sources before any numerical claim. This kernel alone is NOT the complete genus-two CFT partition function: oscillator determinant, moduli-dependent factors, and modular covariance require verification.

## Physical checks required before computing
(A) derive normalized left/right momenta from G,B with explicit alpha' convention;
(B) test Sp(4,Z) transformation/covariance with the appropriate weights, not merely theta equality;
(C) test separating degeneration Omega12→0 and factorization into genus-one objects with correct normalization;
(D) test nonseparating degeneration and expected propagation channels;
(E) compare exact existing code-CFT examples and their known genus-two distinctions.

## New claim candidate and falsification
Propose a *minimal distinguishing Fourier coefficient or degeneration order* for a specified pair of genus-one-isospectral code-CFTs. First establish whether this coefficient/order is already known. Derive it using integer/rational arithmetic or exact q-series coefficients where possible; test alternative code representatives, dualities and parity. Prove invariance under the correct equivalence relation. If only a rediscovery, record negative result.

## Hard gates
P15 = research design only. No computed genus-two partition function, no new theorem, no physical normalization certification, no manuscript. P16 would require primary-source normalization derivation and exact reference-case reproduction. P17 would require genuinely new coefficient/minimality theorem with independent validation. Publication decision is a new gate, not automatic resumption of the old P15-P17 writing schedule.
